# 个人系统 Skills

[English](personal-system-skills.md) | [简体中文](personal-system-skills.zh-CN.md)

## 这是什么

这是一组适合公开的可复用 Agent Skills，覆盖个人操作系统、Agent 治理、每日记录、对话收尾、创作者报价评估和稳定的视觉生成。

这些是本地工作流经过脱敏后的版本。它们保留可复用结构，同时移除本机私有路径、账号标识、私有归档、本地证据和个人记录。

## 包含的 Skills

| Skill | 用例 | 公开边界 |
| --- | --- | --- |
| `universal-methodology` | 在执行前厘清模糊或高风险事项。 | 只包含通用方法论。 |
| `agent-os-global` | 将 Agent OS 风格的治理应用到非简单任务。 | 只使用占位路径。 |
| `agent-os-operation` | 安全地修改或审查 Agent OS 项目。 | 只包含通用治理项目结构。 |
| `daily-log` | 创建或更新每日日志与维护记录。 | 只使用模板路径。 |
| `open-methodology-md` | 打开本地阅读器中的最新方法论 Markdown 文件。 | 只使用占位本地路径。 |
| `codex-closeout-archive` | 将 Agent 对话保存成精简的过程资产。 | 不包含对话原文或会话内容。 |
| `creator-pricing` | 评估创作者赞助报价和谈判方案。 | 只包含公开评估框架。 |
| `calm-mint-pencil-cover` | 生成稳定的薄荷绿色铅笔风封面。 | 只包含视觉风格提示。 |

## 为什么质量较高

- 每个 Skill 捕获的是可重复工作流，而不是一次性提示词。
- 敏感的本地工作流通过占位符和边界表达。
- Skill 范围足够窄，未来的 Agent 无需读取无关上下文即可使用。
- 这组 Skills 将决策方法、Agent 治理、记录管理、商业评估和视觉生成分开处理。

## 最适合的用例

- 为个人或团队构建 Agent 操作层。
- 在不复制完整对话的情况下保持 Agent 工作可追溯。
- 把重复的本地工作流转化为更安全的可复用 Skills。
- 发布私有工作流中适合公开的版本。

## 边界与风险

- 这些公开 Skills 是模板，不是私有系统可以直接替换使用的副本。
- 使用前应把占位路径和工具替换为自己的本地配置。
- 不要公开生成日志、私有记录、本地归档、密钥、凭证或私有验证输出。
- 对高成本创作者报价作决定前，应重新核对当前公开数据和私有活动数据。

## 我的使用状态

这些 Skills 是我实际使用或本地维护工作流的公开安全版本。

## 使用前重新检查

- 本地路径约定是否仍与当前机器一致。
- 治理和隐私政策是否符合你的风险模型。
- 本地工作流依赖的上游工具是否改变了行为或许可证。
