# Personal System Skills

## What This Is

A public-safe bundle of reusable agent skills for personal operating systems, agent governance, daily records, conversation closeout, local data workflows, creator pricing, and stable visual generation.

These are sanitized versions of local workflows. They preserve reusable structure while removing private machine paths, account identifiers, private archives, local evidence, and personal records.

## Included Skills

| Skill | Use Case | Public Boundary |
| --- | --- | --- |
| `universal-methodology` | Clarify ambiguous or high-stakes matters before execution. | Generic methodology only. |
| `agent-os-global` | Apply Agent OS style governance to non-trivial agent work. | Placeholder paths only. |
| `agent-os-operation` | Modify or audit an Agent OS project safely. | Generic governance project layout only. |
| `daily-log` | Create or update daily logs and maintenance notes. | Template paths only. |
| `open-methodology-md` | Open the latest methodology Markdown file in a local reader. | Placeholder local paths only. |
| `codex-closeout-archive` | Preserve an agent conversation as a concise process asset. | No transcripts or session contents. |
| `wechat-chat-export` | Build or run authorized local WeChat export workflows. | No raw data, IDs, keys, local paths, or private output. |
| `creator-pricing` | Evaluate creator sponsorship pricing and negotiation options. | Public evaluation framework only. |
| `calm-mint-pencil-cover` | Generate a stable mint colored-pencil article cover style. | Visual style prompt only. |

## Why It Is High Quality

- Each skill captures a repeatable workflow rather than a one-off prompt.
- Sensitive local workflows are expressed through placeholders and boundaries.
- Skill scope is narrow enough for future agents to use without reading unrelated context.
- The bundle separates decision methodology, agent governance, record keeping, local export safety, business evaluation, and visual generation.

## Best Use Cases

- Building a personal or team operating layer for agents.
- Keeping agent work traceable without copying full conversations.
- Turning repeated local workflows into safer reusable skills.
- Publishing public-safe versions of private workflows.

## Boundaries And Risks

- These public skills are templates, not drop-in copies of a private system.
- Replace placeholder paths and tools with local equivalents before use.
- Do not publish generated logs, raw exports, chat records, account IDs, local archives, keys, credentials, or private validation output.
- High-cost creator pricing decisions should verify current public data and private campaign data before commitment.

## My Usage Status

These skills are public-safe adaptations of locally used or locally maintained workflows.

## Recheck Before Use

- Whether local path conventions still match your machine.
- Whether governance and privacy policies fit your risk model.
- Whether any upstream tools used by local workflows changed behavior or license.
