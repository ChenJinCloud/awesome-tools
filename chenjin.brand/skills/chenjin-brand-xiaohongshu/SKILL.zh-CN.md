# 陈今品牌竖图

按陈今已经形成的视觉偏好制作清楚易读的 3:4 竖图。默认画布为 1080 × 1440 CSS 像素，输出 PNG，并保留可编辑 HTML/CSS 和结构化文案。用户当次的明确要求优先。

设计前读[视觉基线](references/visual-system.zh-CN.md)。使用配套渲染器时读[输入格式](references/input-schema.zh-CN.md)。

## 设计判断

- 先确定这一页的用途及阅读顺序。个人介绍适合人物照片与四项成绩；普通正文根据内容安排版式。
- 保留原文姓名、数字限定词、日期与归属。真实照片保留原貌，裁切应保证人物完整。示例成绩属于样例数据，不是后续可自动复用的个人事实。
- 微暖月白 `#F2F1EC` 做底，青黛 `#223939` 做文字，低饱和青绿 `#527C6D` 做强调。用柔和卡片和克制的浅阴影形成层次。并列事项使用协调的圆点。
- 标题直接表达信息。介绍模板由项目与角色标题直接进入成绩框，删去“增长现场”这类重复标签。
- 顶部贯穿画布的深色横杠是默认的系列识别元素。文字缩到手机宽度后仍需清楚，减少装饰性标签。使用本地字体，并在实际 PNG 中检查中文显示。
- 普通内容系列的第一张标题下直接有正文，按自然内容边界分页。放不下就增加页数，不统一缩小文字，也不把长截图机械切片。

## 制作

每次修改另建输出目录。配套渲染器提供基于已确认介绍卡的 `intro` 模板，以及显式分页的 `content` 模板。模板作为起点，其他内容可以调整 HTML/CSS。

```bash
python3 scripts/render.py examples/intro.zh-CN.json --output /path/to/new-output
python3 scripts/render.py examples/content.zh-CN.json --output /path/to/new-output
```

只生成 HTML 时加 `--sources-only`；替换介绍卡照片时加 `--portrait /path/to/photo.jpg`；`--scale 2` 会从 HTML 直接渲染 2160 × 2880 PNG。

PNG 导出需要 Python 3 与 `ego-browser`。当前任务已有 Ego Lite TaskSpace 时传 `--space ID`，迭代期间加 `--keep-space`。导出失败会记录 Space ID，恢复时继续使用该 Space。遵守浏览器当前的控制权与交接状态。持续无法截图时交付源码并说明失败；只有当前任务的工具路由规则允许时才换用其他渲染器。

渲染器检查边界并保存报告。文字越界时停止导出，不静默缩小字号；重新分页或调整版式后再次导出。

## 检查与交付

逐张打开实际 PNG，检查中文、人物裁切、圆点对齐及区块间距，同时核对成绩标签。对照原文检查数字的 `+` 号和时间范围。发现问题后修改源码并重新渲染。
