# X 原帖 3:4 截图

[English](SKILL.md) | [简体中文](SKILL.zh-CN.md)

用户提供 X 帖子链接，或要求将 X 原帖截图用于小红书时，使用此 Skill。直接截取浏览器实际显示的原帖。保留作者和头像、账号名、正文及配图，以及时间和页面显示的真实数据。不增加外框、独立封面、标题、水印、页码或装饰底板；不使用 SVG、HTML 模板或生图重建原帖。

测量和截图前，阅读[截图指南](references/capture-guide.zh-CN.md)。执行环境需要支持布局检查和精确区域截图的浏览器；本包提供操作指令，不包含独立浏览器执行器。

## 工作流程

1. 使用用户指定的浏览器。未指定时使用可用的浏览器工作流，有 Ego Lite 时优先使用。确认目标原帖可见，展开折叠正文，等待字体和图片加载。登录或验证由用户完成；复用已验证窗口，再次检查实际原帖。
2. 记录原始正文及顺序。按下表临时调整原帖布局，保留字体族和颜色。X 的布局可能变化，应测量实际正文边距。
3. 每页尽量放入完整段落或图片，在容量内选择最后一个可用分界。不预定页数后平均分配。第一张包含作者区域并紧接正文，最后一张包含真实帖尾信息。
4. 以 2 倍像素密度截取原生页面区域。即使截图失败，也要恢复临时样式和视口设置。
5. 核对正文一致性，检查完整段落或文字行是否全部覆盖，同时检查配图与 PNG 实际尺寸。逐张查看图片，交付按顺序编号的 PNG、仅含成品 PNG 的 ZIP 和首张预览。

## 默认排版

| 项目 | CSS 像素 | PNG 像素 |
| --- | --- | --- |
| 每张图片 | 600 × 800 | 1200 × 1600 |
| 像素密度 | 2 | — |
| 含原有内边距的帖子列宽 | 约 580 | 约 1160 |
| 正文每侧实际边距 | 约 26 | 约 52 |
| 正文字号 | 16 | 32 |
| 正文行距 | 20 | 40 |
| 顶部预留 | 12 | 24 |
| 单张内容最大高度 | 780 | 1560 |

用户明确指定的参数优先，保持竖版 3:4。超长段落可以在完整文字行之间分张，并保留少量重叠，随后验证覆盖。超大配图单独安排，不擅自裁掉内容。不缩小整帖来凑页数。

## 完成证据

在本地保存 `capture-manifest.json`，记录输入链接和实际页面链接、截图时间、浏览器、视口和像素密度，以及布局参数、裁切区间、输出尺寸和正文覆盖检查结果。失败截图另存调试目录，修订版使用新的输出目录。

Loading 页面、验证遮罩或藏在验证后的原帖均属于未完成。报告实际阻碍，保留浏览器窗口供恢复。不得隐藏登录或验证遮罩来制造成功截图。本 Skill 不授予在小红书或 X 发布的权限。
