# 创作者报价评估

[English](SKILL.md) | [简体中文](SKILL.zh-CN.md)

当用户需要判断创作者报价是否合理、如何谈判或是否续约创作者合作时，使用此 Skill。

## 输入

询问或推断：

- 频道 URL 或账号；
- 报价和交付形式；
- 目标市场与受众地域；
- 近期平均播放量；
- 订阅者数量；
- 赞助形式：独立视频、植入、短视频、Newsletter 或组合方案；
- 活动目标：转化、发布认知、建立信任或实验。

## 数据检查

条件允许时，检查近期公开频道数据：

- 最近 10 个长视频；如果刚发布的视频还没有足够时间积累表现，则排除；
- 平均播放量；
- 播放量与订阅者比例；
- 互动率；
- 发布频率；
- 近期增长趋势；
- 受众地域（如果创作者或平台截图可以提供）。

## 评估框架

按 1 到 5 分评分：

| 维度 | 检查内容 |
| --- | --- |
| 品类匹配 | 内容是否接近产品购买者或用户？ |
| 受众匹配 | 受众是否符合目标地域和角色？ |
| 内容质量 | 创作者能否清晰解释复杂产品？ |
| 数据质量 | 播放量、互动、增长、一致性和评论。 |
| 竞争环境 | 近期赞助、商业饱和度或直接竞品曝光。 |

然后将报价与隐含 CPM 比较：

```text
implied_cpm = quoted_price / expected_views * 1000
```

地区和品类基准只能作为参考，不要把 CPM 当成全部决策依据。

## 建议等级

- 强烈建议：匹配度高、数据健康、价格在可接受范围内，并且活动目标明确。
- 谈判：匹配度良好，但价格、交付内容或风险分配需要调整。
- 实验：匹配度不确定；使用较低预算、效果分成或较小范围。
- 拒绝：匹配度低、价格虚高、受众不符或存在直接竞品冲突。

## 谈判选项

提供结构化选项，而不只是压低价格：

- 较低固定费用加效果奖金；
- 先进行较小的首次植入，再决定较大的续约；
- 多次发布组合，并设置审查门禁；
- 未达到最低播放门槛时的补偿条款；
- 用创作者自主权换取更好的价格或时间灵活性。

## 输出格式

```markdown
结论：
合理价格范围：
报价评估：
关键风险：
建议的谈判姿态：
建议消息：
哪些变化会改变结论：
```

## 约束

- 在提出高成本建议前核对当前公开数据。
- 不得编造私有分析数据。
- 区分漏斗顶部价值和直接转化。
- 谈判措辞应保持尊重并维护关系。
