# 每日日志

[English](SKILL.md) | [简体中文](SKILL.zh-CN.md)

当用户希望记录一天、更新日志、比较计划与实际执行，或追踪基础维护状态时，使用此 Skill。

## 配置路径

为你自己的系统设置：

```text
DAILY_LOG_ROOT=<你的每日日志文件夹>
MAINTENANCE_ROOT=<你的维护或基础状态文件夹>
```

建议的每日日志文件名：

```text
YYYY/YYYY-MM/YYYY-MM-DD.md
```

## 每日模板

```markdown
# YYYY-MM-DD 每日日志

## 概览

## 原始计划

## 实际时间线

## 已完成

## 未完成 / 顺延

## 偏差与原因

## 基础状态
- 睡眠：
- 饮食：
- 运动：
- 卫生：
- 外出：
- 情绪：

## 关键沟通 / 决定

## 风险信号

## 明日最小行动

## 来源
```

## 工作流

1. 从用户输入或当前本地日期确定日期。
2. 如果每日日志不存在则创建，否则读取已有文件。
3. 按时间顺序向“实际时间线”追加更新。
4. 将完成的事项移至“已完成”。
5. 在“基础状态”记录健康或维护信号。
6. 收尾时总结偏差，并选择明日最小行动。

## 约束

- 不要过度润色原始每日日志。
- 私有细节保留在本地。
- 当用户把日志用作证据时，保留来源记录。
