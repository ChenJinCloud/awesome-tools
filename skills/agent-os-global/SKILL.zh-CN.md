# Agent OS 全局治理

[English](SKILL.md) | [简体中文](SKILL.zh-CN.md)

当 Agent 任务可能影响未来上下文、记录、规则、权限或工作连续性时，使用此 Skill。这是可移植的公开版本；请将占位路径替换为你自己的本地操作系统路径。

## 权威输入

在你的环境中定义：

- `AGENT_OS_ROOT`：包含 Agent 治理文档的文件夹。
- `LIFE_OS_ROOT`：包含持久个人或团队记录的文件夹。
- `GLOBAL_WORK_LEDGER`：用于非项目工作的轻量台账。

建议的治理文件：

- `README.md`
- `source-of-truth-map.md`
- `permission-matrix.md`
- `agent-behavior-contract.md`
- `recording-policy.md`

## 工作流

1. 判断事项类型、风险等级、目标交付物和可能的记录位置。
2. 只读取当前任务需要的治理文件。
3. 执行最小但有用的动作。
4. 如果任务改变持久上下文，将结果写入正确的记录路径。
5. 如果不存在具体路径，添加一条轻量台账记录。
6. 如果出现重复纠正或失败，更新或提出政策、经验、Skill 或适配器变更。
7. 在红色动作前停止。

## 红色动作

删除、对外发送或发布、花费资金、修改凭证或权限、启用工具或后台 Agent、作出法律或医疗承诺、扩大跨磁盘写入范围，以及其他不可逆动作，都必须先询问。

## 收尾标准

每个非简单任务都应该以下列一种结果结束：

- 一个持久记录路径；
- 一条全局台账记录；
- 一段说明为什么不适合记录的简短理由。
