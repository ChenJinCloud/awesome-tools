# 薄荷绿色铅笔风封面

[English](SKILL.md) | [简体中文](SKILL.zh-CN.md)

使用此 Skill 保持稳定的文章封面视觉语言：

- 超宽 21:9 构图；
- 手绘彩色铅笔质感；
- 低饱和薄荷绿、鼠尾草绿、浅水蓝、灰绿色、米白和淡冷灰色；
- 平静、通透、具有恢复感的氛围；
- 留有充足负空间；
- 不出现文字、Logo、水印、人物、建筑、强烈对比、饱和色或照片写实感。

## 工作流

1. 默认使用图像生成工具。
2. 保持固定的风格常量。
3. 只改变用户要求的场景或主题。
4. 如果用户只给出文章主题，选择能够支持该主题的安静自然场景。
5. 先生成一张完成度高的封面；只有核心约束被破坏时才迭代。

## 场景映射

- 倦怠或恢复：蜿蜒溪流、安静山丘、薄雾和细小草木。
- 不确定或转变：通往浅色林间空地的小径。
- 休息或安全：有芦苇和柔和晨雾的静谧湖畔。
- 自我关怀：被包围的草地、低矮野花和柔和天空。
- 清晰或专注：极简山脊、开阔天空和纤细小径。
- 心流或移动：缓慢河湾、踏脚石和漂浮云层。
- 更新或成长：幼苗、起伏田野和雨后微光。
- 孤独或悲伤：雾中田野或树叶上的柔和细雨，不阴郁、不戏剧化。

## 提示词模板

```text
创作一张平静的 21:9 文章封面插画，采用手绘彩色铅笔风格。
场景：{scene}。
使用低饱和薄荷绿色调，搭配柔和鼠尾草绿、浅水蓝、灰绿色、温暖米白和淡冷灰色。
氛围应当平静、通透、具有恢复感和内省感。
加入细微纸张纹理、精细铅笔线条、柔和漫射自然光和充足负空间。
保持超宽、简洁、平衡的构图，适合作为文章封面。
不要文字、Logo、水印、人物、建筑、强烈对比、饱和色或照片写实感。
```

## 质量检查

- 它看起来像一张 21:9 封面吗？
- 色板是平静的薄荷绿和鼠尾草绿，而不是饱和的绿色或蓝色吗？
- 它是否安静、通透？
- 是否完全没有文字或水印？
- 场景改变时，视觉语言是否保持一致？
