# 通用方法论

[English](README.md) | [简体中文](README.zh-CN.md)

此目录是 Universal Methodology Codex Skill 的公开权威软件包。

当前软件包使用方法论 v1.2。它帮助 Agent 在扩大执行前，判断模糊、高风险或具有复用价值的工作应当继续推进、暂停、缩小范围、结束，还是转化为可复用的过程资产。

## 安装

将此目录以 `universal-methodology` 名称复制到 Codex Skills 目录，然后刷新 Skill 发现或开始新任务。

完整推进模板提供[简体中文](references/project-progression-card.md)和[英文](references/project-progression-card.en.md)版本。
